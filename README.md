# Sonic Canvas

Musik wird Gemälde. Datei hochladen — Bild entsteht. Alles läuft im Browser.

Dieselbe Datei erzeugt dasselbe Bild. Stimmung und Form kommen aus Spektrum, Energie und Hüllkurve.

## Lokal

Kein Build.

```bash
python3 -m http.server 4173
```

MP3, WAV, OGG und M4A, soweit der Browser sie dekodiert. Grenze Stufe 1: 25 MB.
